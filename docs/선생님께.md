# 선생님께 — 「별 헤는 밤」 한 장 안내

윤동주의 시를 하루 3분씩 읽고, 따라 적고, 반 친구들과 감상을 나누는 앱입니다.
휴대폰에서 아래 주소를 열면 바로 쓸 수 있습니다. 설치할 것은 없습니다.

**주소:** `https://________________________` ← 배포한 사람이 채워 넣습니다

> 브라우저 메뉴에서 **홈 화면에 추가**를 누르면 앱처럼 아이콘이 생깁니다.

---

## 수업에서 쓰는 순서

1. **선생님이 먼저 가입**합니다(아이디와 숫자 PIN 4~12자리).
2. **방** 탭 → 방 이름(예: 3학년 2반) → **만들기**.
3. 방 위의 ⓘ 를 누르면 **초대 코드**가 화면 아래에 뜨고 자동으로 복사됩니다. 칠판에 적어 주세요.
4. 학생들이 각자 가입한 뒤 **방** 탭 → 초대 코드 → **들어가기**.

## 학생이 하는 것

- **길**: 윤동주가 머문 곳을 따라 시를 한 편씩 걷습니다. 한 마디가 3분쯤입니다. 천천히 읽기 → 문제 두 개 → 마음에 남은 것 → 한 줄 감상.
- **원고지 필사**: 시를 원고지 칸에 옮겨 적고 그림으로 내려받습니다.
- **시험 대비**: 틀린 문제를 모아 다시 풉니다. 걸어 본 시에서만 묻습니다.
- **방**: 자기가 쓴 한 줄 감상이나 필사를 골라 반에 나눕니다.

## 선생님만 할 수 있는 것

| 무엇 | 어디서 |
|---|---|
| **반 살펴보기** — 학생마다 걸은 마디, 연속일, 필사, 오답 수, 마지막으로 한 날 | 방 위의 '반 살펴보기' |
| **글 가리기 / 되돌리기** | 글 옆 ⋯ → 이 글 가리기 |

- 반 살펴보기에는 **숫자만** 나옵니다. 학생이 쓴 감상의 원문은 학생이 '방에 나누기'를 눌렀을 때만 방에 보입니다.
- '멈춤'은 사흘 넘게 아무것도 하지 않은 학생입니다. 맨 위에 옵니다. 혼낼 학생이 아니라 말을 걸어 볼 학생이라는 뜻으로 두었습니다.

## 반이 스스로 지키는 장치

- 서로 다른 **세 사람이 신고**하면 글이 저절로 가려집니다. 누가 신고했는지는 아무에게도 보이지 않습니다.
- **차단**하면 차단한 학생의 화면에서만 상대 글이 사라집니다. 상대는 모릅니다.
- 가린 글은 지워지지 않습니다. 선생님과 글쓴이는 원문을 볼 수 있어 무엇이 문제였는지 판단할 수 있습니다.
- 학생은 「나」 맨 아래에서 **계정을 지울** 수 있습니다. 기록과 방에 쓴 글이 함께 지워집니다. 선생님이 계정을 지우면 방은 남고, 가장 먼저 들어온 학생이 방장이 됩니다.
